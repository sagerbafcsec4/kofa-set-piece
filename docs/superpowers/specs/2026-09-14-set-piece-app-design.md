# セットプレーExcel作成アプリ 設計書（2026-09-14）

## 目的

Optaから手動で落とした「セットプレー得点／失点」のExcel2枚を、毎節、日本語クラブ名・決まった体裁の
「セットプレー情報.xlsx」に作り直す作業を、ブラウザで開いてファイルを落とすだけにする。
前回はCodex専用部品に依存した1回きりの台本（build_set_piece.mjs）だったため、毎回AIに頼む必要があった。

## 対象範囲

- 入力: Opta「What Scored - Goals」「What Conceded - Goals」（`#5Goals.xlsx` 等の名前でも可）
- 出力: 1ブック1シートのExcel（得点表＋失点表）
- リーグ: プレミアリーグ／ラ・リーガ／エールディヴィジ（`LEAGUE_OPTIONS` で追加可）
- 対象外: Optaサイトへの自動接続、テンプレの差し替え機能、旧A〜H列（英語の元表）の再現、他リーグの辞書整備

## 画面と操作

1. **読み込む**: 得点用／失点用の2枠（ドラッグ＆ドロップ／クリック）。2つまとめて落とすと `Conceded` を含む方を失点用へ。
2. **設定**: リーグ（プルダウン）・シーズン（前後1年＋自由入力）・節（1〜38）。辞書の読み込み状況を表示（再読込ボタン）。
3. **実行**: 部品・辞書・2ファイル・シーズン・節が揃うまでボタンは押せない。
4. **結果**: 要約／警告（未登録クラブ・クラブ数不一致 等）／ダウンロードボタン（自動でダウンロードも開始）／照合表／処理ログ。

## データ取得と整形

- Optaの列は1行目の見出し名で解決（小文字化・空白圧縮）。必須列欠落・数値でない値・エラー値は中止。
- `Goals From Set Piece %` は100倍値 → ÷100（`Math.round(v*100)/10000`）。
- 辞書: 内蔵表 `BUILTIN_DICT` から `Opta表記(正規化) → 日本語名` の Map を作り、共有シートCSV（`fetch(..., {cache:'no-store'})`・15秒で時間切れ）の選択リーグ行に「Opta表記」があれば上書き。`;`区切り・NFC正規化・小文字化。シートが読めなくても内蔵表で続行（警告表示）。
- 並び: Set Piece 降順 → Opta Total 降順 → 日本語名昇順。

## 対戦チームの色付け（2026-09-15追加）

- 「色付けする」ON → 試合の行（ホーム／アウェイ＋色）。まとめて貼り付け可。試合数ぶん表を右へ複製（9列ピッチ）し、各表でその2クラブの行を塗り＋太字。色は薄めの8色パレット、既定は試合順に割り当て。全セル照合は全ブロックに掛ける。

## 検証

- 実行時（アプリ内）: クラブ数／得点と失点の集合一致／出来上がりのTotal列の再集計＝元の `Goals From Set Piece` 合計／未登録クラブ。合計不一致はファイルを出さない。
- 開発時: `tests/e2e_run.py`（部品テスト＋Playwrightでアップ→実行→ダウンロード）→ `tests/verify_output.py`（openpyxlで値・並び・体裁・数式/エラー無し・合計を照合）。2026-09-14 実データ（ラ・リーガ第5節）で 25/25 PASS。

## 公開

- GitHubにコミット・push（正本）→ `本番へ送る.bat`（deploy.py）で `index.html` だけを Cloudflare Pages へ手動送信 → 公開URLから取り直して照合。
- Cloudflare Access（メールコード）はユーザーがCloudflare画面で設定。

## 部品の癖（実測で判明）

- ExcelJS: 列幅がちょうど 9 だと「既定幅」扱いで書き出さない（→ 9.005）。結合セルはどの順で体裁を入れても同じバイト列を出力し、2番目以降のセルにも書式が書かれる。
- openpyxl: 結合範囲の2番目以降を `MergedCell`（文字・塗りなし）として読み、外周罫線だけを各セルに合成する。検査はこの見え方に合わせている。
